# Code of Conduct

## Our standard

The homebridge-eg4 project welcomes constructive participation from users and contributors of all experience levels.

Please:

- Be respectful and professional.
- Focus criticism on code, behavior, documentation, or technical decisions rather than people.
- Assume good intent while still raising security, reliability, or safety concerns clearly.
- Respect privacy. Do not post passwords, session cookies, private API captures, personal addresses, or other sensitive information.
- Avoid harassment, threats, discriminatory language, personal attacks, and deliberately disruptive behavior.
- Give maintainers and contributors reasonable time to review reports and proposed changes.

## Technical and safety discussions

This plugin interacts with solar, battery, grid, load, and generator monitoring data. Discussions about equipment behavior should clearly distinguish observed telemetry from assumptions or unverified control behavior.

The project is intentionally read-only. Contributions that add equipment-control functionality should not be submitted without prior discussion with the maintainer.

## Enforcement

Project maintainers may edit, hide, lock, or remove comments, issues, pull requests, or other contributions that violate these expectations. Repeated or serious violations may result in restricted participation.

## Reporting

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.

For conduct concerns, contact the maintainer privately through an appropriate GitHub contact method rather than posting personal details publicly.

## Scope

These expectations apply in the project's GitHub repository, issue tracker, pull requests, discussions, and other project-managed spaces.
